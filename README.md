# QR Thanh Toán - Nguyễn Hoàng Kha

Ứng dụng hiển thị mã QR chuyển khoản ngân hàng (MBBank, Vietcombank) cho Nguyễn Hoàng Kha, được viết bằng React + Vite + TypeScript + Tailwind CSS.

## Tính năng
- **Hiển thị thông tin ngân hàng chính xác**: MBBank (STK: `70047705081999`) và Vietcombank (STK: `1055833228`).
- **Mã QR chuẩn Napas 247**: Quét nhanh chóng trên mọi ứng dụng ngân hàng và ví điện tử.
- **Phóng to mã QR**: Nhấp vào mã QR để mở chế độ xem toàn màn hình rõ nét.
- **Sao chép số tài khoản 1-chạm**: Tự động sao chép vào bộ nhớ tạm (clipboard) kèm thông báo toast xác nhận.
- **Tải ảnh mã QR**: Hỗ trợ tải trực tiếp mã QR SVG về thiết bị.
- **Giao diện Tech Cyberpunk**: Hiệu ứng neon ambient glow và perspective 3D grid animation chuyển động mượt mà.

## Khởi chạy dự án
```bash
npm install
npm run dev
```
Cổng chạy mặc định: `http://localhost:3000`
